# ⚡ Calculadora Inteligente de Consumo Elétrico

Uma aplicação desenvolvida em **Python** para calcular o consumo mensal de energia elétrica de equipamentos de forma simples e prática.

### 🐍 Linguagem utilizada

* **Python**

### 📐 Fórmula utilizada

```text
consumoMensal = (potencia × horasDia × 30) / 1000
```

### 💻 Como utilizar

Para executar o programa, basta informar:

1. O **nome do equipamento** que deseja calcular;
2. A **potência do equipamento**, em watts (W);
3. A quantidade de **horas utilizadas por dia**.

Após inserir os dados, o programa realiza automaticamente o cálculo do **consumo mensal estimado em kWh**.

### 🎯 Objetivo

O projeto tem como objetivo facilitar a estimativa do consumo de energia elétrica de diferentes equipamentos, utilizando uma aplicação simples desenvolvida em Python.
